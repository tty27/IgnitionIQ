IgnitionIQ 🚗

Making Automotive Learning More Interactive

IgnitionIQ is a web-based automotive learning platform developed as my final-year Software Engineering project. It aims to make learning about cars, road safety, traffic rules, and driving scenarios more engaging through interactive learning experiences and gamification.

The project combines automotive education with features designed to encourage users to explore, practise, and improve their knowledge.

📌 Project Overview

Learning about automotive topics and road safety can be more engaging when information is presented through interactive experiences rather than passive reading alone.

IgnitionIQ explores how gamification can support a more engaging learning experience by incorporating quizzes, progression, scoring, and other interactive features into an automotive learning platform.

Project type: Final-year university project  
Category: Web Application / Automotive Education  
My role: Student Developer  
Focus: Web Development, User Experience, Feature Implementation

✨ Key Features

The project includes the following features, subject to the implementation available in the current version:

- Automotive Learning: Explore automotive knowledge and car-related topics.
- Car Recognition: Learn to identify and recognise different cars.
- Traffic Rules: Explore traffic rules and road safety knowledge.
- Driving Scenarios: Learn through scenarios related to driving situations.
- Interactive Quizzes: Test knowledge through question-based learning.
- Gamification: Use levels, experience points, scoring, and hints to make learning more interactive.
- Leaderboards: Compare scores and encourage friendly competition, where implemented.

🛠️ Technology Stack

The project was developed using modern web technologies, including:
